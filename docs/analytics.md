# Аналитика HRNEIROWAY

Основной счётчик: `111505107`. Общий модуль: `/assets/js/site-analytics.js`. Подключён к 21 содержательной странице из sitemap и к политике. На политике счётчик не запускается, доступны только настройки выбора. На 404 и закрытом прототипе счётчик не подключён.

## Выбор посетителя

Метрика загружается только после «Разрешить аналитику». «Без аналитики» оставляет сайт рабочим. Кнопка «Настройки аналитики» позволяет изменить выбор. Выбор хранится в localStorage под ключом `hrneiroway-analytics-choice-v1`; старое закрытие технического уведомления не считается согласием. При недоступном хранилище выбор действует до ухода со страницы. При отзыве счётчик уничтожается, страница перезагружается. На других открытых вкладках учитывается изменение выбора.

Вебвизор, карта кликов, автоматическое отслеживание внешних ссылок, электронная коммерция, передача заголовков и менеджер тегов отключены. На локальном предпросмотре аналитика не запускается даже при разрешении. События не читают поля и не передают текст документов, адрес ссылки или имя проекта. URL запуска и referrer передаются без query/hash.

## Цели для кабинета Метрики

В интерфейсе счётчика нужно проверить/добавить цели типа «Целевое событие», условие «совпадает»:

| Название | Идентификатор | Параметр category |
|---|---|---|
| Переход к контакту | `contact_click` | telegram, email, max, whatsapp, vk, instagram, pinterest, phone |
| Открытие работы | `project_open` | portfolio |
| Нажатие экспорта инструмента | `tool_export` | print, download, copy |

В параметре `page` отправляется только путь страницы. Для сравнения каналов используйте параметр `category`. Ссылка на набор стикеров не считается контактом. Нажатие кнопки экспорта не доказывает, что пользователь сохранил файл; переход к контакту не доказывает получение заявки.

Код отправки целей добавлен. Создание/проверка целей и появление статистики в закрытом кабинете не подтверждены без доступа к нему. `reachGoal` должен совпадать с идентификатором цели в кабинете: https://yandex.ru/support/metrica/ru/objects/reachgoal

## Проверка

`node tests/site-analytics.test.cjs`

Проверяет запуск только после выбора, отсутствие повторного запуска, отказ/отзыв, смену решения между вкладками, заблокированное хранилище, отсутствие параметров и фрагментов URL, категории событий, исключение набора стикеров, работу на инструментах, отсутствие счётчика на политике и предпросмотре.

Перед дальнейшим изменением аналитики проверить актуальность политики и работу обоих вариантов выбора. Не включать запись полей инструментов без отдельной проверки обработки данных.
